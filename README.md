# Find Max Distance Between Two Circles

This repository contains a MATLAB function for calculating the **maximum possible distance between two circles** based on their centers and radii.

The function is useful in computational geometry, simulations, collision detection, and spatial analysis problems.

---

## 📌 Features

- Computes the maximum distance between two circles
- Simple and lightweight MATLAB implementation
- Suitable for academic, research, and engineering use cases
- Easy to integrate into existing MATLAB projects

---

## 📂 File Structure

📐 How It Works

Calculates the Euclidean distance between the two circle centers

Adds both radii to the center distance

Returns the maximum possible separation between the circles

🚀 Applications

Computational geometry

Physics simulations

Robotics & path planning

Collision detection systems

Academic and educational projects

🛠 Requirements

MATLAB (R2018 or newer recommended)
